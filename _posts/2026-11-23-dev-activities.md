## LoL문철 — 풀스택 팀 프로젝트

LoL(리그 오브 레전드)을 테마로 한 풀스택 웹 서비스 팀 프로젝트.

- **스택:** React / FastAPI / SQLite / Gemini AI
- **한 일:** 인증, 투표, 랭킹, 영상 분석 기능에서 생긴 프론트엔드·백엔드 버그를 처리했다.
- **배운 점:** 프론트와 백을 오가며 디버깅하는 과정에서, 기능 하나가 여러 계층에 걸쳐 있을 때 어디서 문제가 나는지 끊어서 보는 감을 익혔다.

---

## 따릉이 데이터 자료구조 프로젝트

- **데이터:** 서울시 공공자전거 따릉이 대여소 정보 + 대여이력
- **역할:** 팀장. 구현에서는 BST(대여소번호·자전거번호)와 자전거별 이동 경로를 담당했다. 최종 보고서와 README 작성도 맡았다.
- **사용 자료구조:** 동적 배열, 연결 리스트, 템플릿, 큐(BFS), BST, 정렬·이분 탐색, 방향 가중 그래프
- **배운 점:** STL 없이 밑바닥부터 짜 보면서, 평소 그냥 가져다 쓰던 자료구조가 내부적으로 어떻게 돌아가는지 다시 보게 됐다.
