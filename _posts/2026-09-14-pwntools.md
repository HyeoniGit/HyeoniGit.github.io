`pwn`: 보안과 해킹 분야에서 특정 시스템이나 프로그램의 취약점을 이용해 제어권을 빼앗는 공격 행위

`pwntools`: 해킹 과정에 도움이 되는 기능들을 모아 둔 도구

---

## 프로세스 통신 기능

### 연결을 맺는 함수

`process()`: 데이터 송수신에 쓰이는 `pwnlib.tubes` 클래스를 반환한다. 인자나 환경 변수도 설정할 수 있다. `p = process(["./example", "AAAA"], env={"LD_PRELOAD": "./libc.so.6"})`처럼 쓰면 AAAA는 `argv[1]`, env는 환경 변수가 된다.

```python
p = process("./example")  # ./example 경로에 있는 프로그램을 실행한 뒤 연결
```

`remote()`: 호스트의 도메인 혹은 IP 주소와 포트 번호를 받아 원격 서버와 통신할 때 쓰는 함수. `pwnlib.tubes` 클래스를 반환한다. UDP로 연결하고 싶으면 포트 번호 뒤에 `typ='udp'`를 넣는다.

```python
r = remote("example.com", 1337)
```

`ssh()`: SSH 서버에 접속해서 통신

```python
s = ssh("dreamhack", "127.0.0.1", port=22, password="dreamhack")
# 127.0.0.1 호스트의 22번 포트에 열린 SSH 서버에
# 사용자 이름 dreamhack, 비밀번호 dreamhack으로 로그인
```

### 데이터 송수신 함수

`recv()`: 수신한 데이터를 bytes 클래스로 반환

```python
p = process('./example')

data = p.recv(1024)            # 최대 1024바이트까지 받아서 저장
data = p.recvline()            # 개행 문자를 만날 때까지 받아서 저장
data = p.recvn(5)              # 정확히 5바이트만 받아서 저장
data = p.recvuntil(b'hello')   # b'hello'가 출력될 때까지 받아서 저장
data = p.recvall()             # 프로세스가 끝날 때까지 받아서 저장
```

`recv()` vs `recvn()`: `recv(n)`은 **최대** n바이트를 받는다. `recvn(n)`은 **정확히** n바이트를 받고, 그만큼 받지 못하면 계속 기다린다.

`send()`: 데이터 전송

```python
p = process('./example')

p.send(b'A')                      # b'A' 입력
p.sendline(b'A')                  # b'A' + b'\n' 입력
p.sendafter(b'hello', b'A')       # b'hello'가 출력되면 b'A' 입력
p.sendlineafter(b'hello', b'A')   # b'hello'가 출력되면 b'A' + b'\n' 입력
```

`sendafter()`, `sendlineafter()`: 위 예시에서 `akakakakakhellodkdkdkdk`라는 데이터가 오면, `akak...hello`까지 받은 뒤 A(또는 A + `\n`)를 입력한다.

`interactive()`: 터미널에서 사용자가 실시간으로 데이터를 주고받을 수 있게 하는 함수

---

### 연결을 종료하는 함수

`close()`: 연결을 끝내고 싶을 때 쓰는 함수. `interactive()`를 호출한 경우에는 그 함수가 끝날 때 연결도 같이 끝나므로 `close()`가 필요 없다.

```python
p = process("./example")
p.close()
```

---

### 로그 출력

주고받는 데이터를 모두 보고 싶으면 `context.log_level`을 debug로 설정한다.

```python
from pwn import *
context.log_level = 'debug'
```

log_level 종류

| 레벨 | 출력 |
|---|---|
| critical | 치명적인 오류 외에는 출력하지 않음 |
| error | 에러 메시지만 출력 |
| warning / warn | 경고 메시지 출력 |
| info | 일반적인 상태 메시지 출력 (설정하지 않으면 기본값) |
| debug | 송수신 데이터, 내부 변수 등 상세히 출력 |

from pwn import *

s8 = 0x41

### GDB

`gdb.attach()`: `process()`, `remote()`로 만든 객체를 넣으면 해당 프로세스에 GDB가 붙어서 실행이 멈추고, GDB 터미널이 열려 디버깅할 수 있다.

```python
p = process("./example")
gdb.attach(p)
sleep(1)  # GDB가 붙을 시간을 벌어 줌. pause()로 대체 가능
```

### Assemble & Disassemble

`context.arch`로 아키텍처를 설정한다.

```python
context.arch = "amd64"  # x86-64 아키텍처
context.arch = "i386"   # x86 아키텍처
context.arch = "arm"    # arm 아키텍처
```

설정한 뒤 `asm()`과 `disasm()`으로 어셈블과 디스어셈블을 한다.

```python
context.arch = "amd64"

machine_code = asm('mov eax, 0')      # 어셈블리를 기계어로 변환
print(machine_code)
assembly_code = disasm(machine_code)  # 기계어를 어셈블리로 변환
print(assembly_code)
```

### ELF

`ELF`: 리눅스 운영체제의 실행 파일 형식

`ELF()`: ELF 파일 경로를 넣으면 `pwnlib.elf.elf.ELF` 클래스를 반환

`symbol`: 함수나 전역 변수 같은 것에 붙는 이름표 (이름과 주소의 대응표)

```python
e = ELF("./example")              # ELF 파일 열기
print(hex(e.symbols['write']))    # 'write' 심볼의 주소
print(hex(e.symbols.write))       # 속성으로 접근
```
