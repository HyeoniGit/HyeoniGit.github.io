시스템 해킹 공부를 시작하면서 가장 먼저 익힌 디버거 명령어를 정리했습니다.

## 실행과 중단

| 명령어 | 설명 |
|---|---|
| `run` (`r`) | 프로그램 실행 |
| `break main` (`b main`) | main 함수에 중단점 설정 |
| `b *0x401136` | 특정 주소에 중단점 설정 |
| `continue` (`c`) | 다음 중단점까지 실행 |
| `info breakpoints` | 설정한 중단점 목록 |
| `delete 1` | 1번 중단점 삭제 |

## 한 단계씩 실행

| 명령어 | 설명 |
|---|---|
| `ni` | 명령어 하나 실행 (함수 호출은 건너뜀) |
| `si` | 명령어 하나 실행 (함수 안으로 들어감) |
| `finish` | 현재 함수가 반환될 때까지 실행 |

## 상태 확인

| 명령어 | 설명 |
|---|---|
| `info registers` (`i r`) | 레지스터 값 확인 |
| `disassemble main` | main 함수 디스어셈블 |
| `x/8gx $rsp` | rsp부터 8바이트 단위로 8개 출력 |
| `x/s 0x402004` | 해당 주소의 문자열 출력 |
| `x/5i $rip` | 현재 위치부터 명령어 5개 출력 |

`x` 명령어 형식은 `x/[개수][형식][단위] 주소` 입니다.

- 형식: `x`(16진수), `d`(10진수), `s`(문자열), `i`(명령어)
- 단위: `b`(1바이트), `h`(2바이트), `w`(4바이트), `g`(8바이트)

## pwndbg에서 자주 쓰는 명령어

| 명령어 | 설명 |
|---|---|
| `context` | 레지스터, 스택, 코드를 한 화면에 표시 |
| `vmmap` | 메모리 맵 (코드, 스택, 힙, 라이브러리 영역) 확인 |
| `telescope $rsp` | 스택의 값을 포인터를 따라가며 표시 |
| `checksec` | 바이너리 보호 기법 확인 |
