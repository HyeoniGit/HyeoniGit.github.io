## Using NASM

Normally if you want to execute a program written in assembly language, you need to assemble it first, which converts it into an object file. After that, you can create an executable file from the object file using a linker.

```bash
nasm -f elf64 program.asm -o program.o
ld program.o -o program
```

## Options of NASM

| 옵션 | 설명 |
|---|---|
| `-f` | Specifies the output format (elf, elf64, win32, win64, etc.) |
| `-o` | Specifies the output file name |
| `-g` | Generates debugging information (when using gdb) |
| `-I` | When using include files, like header files (`%include "filename.h"`) |

```bash
nasm -I ./constants.inc -f elf64 program.asm -o program.o
```
